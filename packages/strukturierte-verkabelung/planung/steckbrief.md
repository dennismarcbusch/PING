# Steckbrief: Strukturierte Verkabelung (Version 2, Kompass 4.0)

| | |
|---|---|
| **Lernproblem** | Schüler lernen die Bereiche und Grenzwerte der DIN EN 50173-1 als Tabelle auswendig. Beim Planen eines echten Gebäudes überspringen sie Ebenen, verbinden Gebäude mit Kupfer, stellen Schränke an das Ende langer Flure oder in Klassenzimmer. |
| **Fach / Beruf / Jahrgang** | Fachinformatik (FISI/FIAE), 10. Klasse |
| **Lehrplanbezug** | LF 3 „Clients in Netzwerke einbinden“ (Netzwerkkomponenten, Topologien, Verkabelung); im Unterrichtsgang nach „Netzwerktopologien“ |
| **Vorwissen** | Netzwerkkomponenten, Sterntopologie und Baum (Paket „Netzwerktopologien erleben“) |
| **Einsatzform** | SeGeL (Standard); Kapitel auch einzeln im klassischen Unterricht nutzbar; freiwilliger Input mit Tafelbild |
| **Geräte** | PC/Laptop; Tablet möglich (Antippen, keine Ziehgesten) |
| **Zeitrahmen** | etwa 120 Minuten, in Einheiten von 30–45 Minuten |
| **Leitsituation** | Korbwerk IT-Service (Ausbilderin Mira Hofmann) plant die Verkabelung des Schulzentrums Lindenau (Hausmeister Ali Demir): zwei Gebäude, 44 Arbeitsplätze. Übungen im Hotel Sonne und in der Druckerei Weiß, Selbstüberprüfung beim Autohaus Seidl. |
| **Typische Fehler** | 1. Ebene überspringen (PC an GV, EV an SV). 2. Kupfer zwischen Gebäuden. 3. LWL bis zum Arbeitsplatz. 4. 100 m statt 90 m. 5. EV am Ende einer langen Etage. 6. Verteiler im Flur oder Klassenzimmer. 7. Querverbindungen zwischen EVs „weil kürzer“. |
| **Arbeitsmittel aus dem Beruf** | Lageplan mit Räumen, Flur als Kabeltrasse, Steigschacht, Hauseinführung; Verteilerschränke; Kabelmedien; Längenberechnung |
| **Welt** | technik · Kulisse Klassenzimmer · Symbol 🔌 |
| **Kerninhalte** | SV, GV, EV, Anschlussdose; Primär-, Sekundär-, Tertiärbereich; LWL OS2, LWL OM4, Cat.7 (Cat.5e veraltet); 1500 m / 500 m / 90 m (+10 m = 100-m-Channel); hierarchischer Stern; Standorte (Technik-, Server-, Nebenraum; nicht Flur, Treppenhaus, Arbeitsräume) |
| **Form** | A Simulation: der Planer aus Version 1 im Simulationsmodus (siehe `konzept.md`) |
| **Paket-ID** | `ping-strukturierte-verkabelung` (neue Aktivität; Version 1 hieß `BSLIF_STRUKTURIERTE_VERKABELUNG`) |
| **Lizenz** | noch offen (Vorschlag CC BY-SA 4.0) |

Übernommen aus Version 1: Gebäude- und Raumdaten von Haus A und B, Kabelführung über Flur, Schacht und Erdtrasse, Längenberechnung (0,16 m je Zeichnungseinheit, 4 m je Etage, Erdtrasse 160 m, 2 m Reserve), die Prüfregeln und die zehn Fragen des Wissenschecks.
