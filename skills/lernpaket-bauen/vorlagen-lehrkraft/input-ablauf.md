# Input „<Thema>“ – Ablaufplan für die Lehrkraft

Dauer: **etwa 20 Minuten** · Material: Tafelbild aus dem Lernpaket · Rolle des Inputs: **freiwilliger Einstieg** (Überblick und Neugier), nicht Ersatz für die Stationen

## Vorbereitung

- Paket ohne Lernplattform öffnen: `index.html#tafel` im Browser (entpackter Ordner). Es startet direkt die Präsentation **ohne Erklärungen**. Taste **F** = Vollbild.
- Alternativ in der Lernplattform: Paket öffnen → **Tafelbild** oben rechts → **E** schaltet die Erklärungen aus.
- Bedienung: **→ / ←** oder Presenter (Bild↓/Bild↑) für die Szenen, Ziffern springen direkt, **P** Stift, **W** Zeichnung löschen, **Esc** schließen. **⌨** zeigt alle Kürzel. Werkzeuge der Szenen: <Kürzel je Szene>.
- Wer nicht teilnehmen möchte, startet direkt im Paket. Jede Szene kommt in einer Station wieder vor.

## Grundmuster jeder Szene: Vorhersagen → Klicken → Deuten

1. **Vorhersagen:** Frage stellen, *bevor* geklickt wird. Alle legen sich fest (Handzeichen, Zuruf).
2. **Klicken:** auslösen bzw. aufdecken.
3. **Deuten:** Eine Schülerin oder ein Schüler erklärt, *warum*. Erst danach das Fachwort nennen.

Leitfrage über allen Szenen: **„<Leitfrage aus der Leitsituation>“**
